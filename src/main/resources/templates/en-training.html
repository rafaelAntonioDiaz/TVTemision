Data Science & Machine Learning

Applied to Petroleum Engineering & Geosciences
3 Days (16.5 Hours) Technical

Intensive in-person course at ACIPET (Bogotá). From Python and EDA to AutoML, Explainable AI (SHAP), and Physics-Informed Machine Learning (PIML).

Key Syllabus:
  • Day 1: Python, EDA, ML Pipelines, Unsupervised Learning (K-Means, PCA).
  • Day 2: Supervised Learning (KNN, SVM, RF), Neural Networks, AutoML (PyCaret, MLJAR).
  • Day 3: Explainable AI (SHAP), PIML/SciML, Symbolic Regression, Capstone.

Instructor: Dr. Pablo Guillen

Dates: January 2027 (TBD) • Location: ACIPET, Bogotá

Target Audience: Petroleum engineers, geoscientists, data analysts, and energy professionals. No prior programming experience is required.

Tools: Python (Anaconda / Google Colab), Scikit-learn, PyCaret, MLJAR, SHAP, SHAPASH, LIME.

Day Core Topics Practice / Examples

Day 2
Supervised ML		 K-NN, Logistic Regression, Random Forest, SVM, Neural Networks, AutoML. Well log property prediction, Seismic facies classification, Benchmarking with PyCaret.
